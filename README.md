Highlights & Rubric Requirements Met
Dashboard Layout: Structured with a distinct Sidebar, Header, and a grid containing 6 realistic financial category cards.

CSS Grid & Flexbox: Uses grid-template-areas for the outer shell and CSS Grid for the card layout, while using Flexbox inside the header, navigation menu, and within each individual card.

CSS Custom Properties: All colors, surfaces, text shades, and shadows are defined as CSS variables inside :root.

Responsive Design: A @media (max-width: 768px) rule collapses the grid into a single-column layout, converting the sidebar into a horizontal scrollable menu bar.

Micro-interactions: Cards feature a 200ms smooth transition that applies a subtle lift (transform: translateY(-4px)) and glow (box-shadow) on both hover and keyboard focus.

Dark Theme (Stretch Goal): Features a dark theme override via the .dark-theme class, easily toggled with the sidebar button.
